BRAIN2CONTROL SYSTEM

WHAT IT IS / 它是什么

不是笔记库，
也不只是一次性的 RAG。For people using AI seriously,
while their context grows out of control.

Brain2 把入口、治理、任务、事件、Agent 协作和维护规则组织成一套可运行、可交接的控制系统。它解决的不是“把资料搜出来”，而是让不同 AI 知道从哪里开始、当前发生了什么、应该如何行动，以及行动后写回哪里。

PRODUCT COMPOSITION

五个组成，
共同形成闭环。Five components,
forming one closed loop.

每个模块都承担一个明确职责。它们不是附加功能，而是让外接大脑能够被接手和长期维护的最低结构。

01

PROTOCOL

定义入口、读取顺序、写入边界与治理规则。

02

SKILL PACK

让不同 Agent 获得执行、判断与协作所需的能力。

03

MAINTENANCE KIT

处理健康检查、冲突、过期信息与持续维护。

04

AGENT START HERE

让新 Agent 快速理解身份、当前上下文和接手路径。

05

UPDATE SERVICE

产品不是一次性交付。更新服务承接协议、Skill 与维护方法的持续演进。

OPERATING LOOP / 工作闭环

01READ读取入口与上下文
→
02ACT按规则行动
→
03WRITE BACK写回结论与变化
→
04HANDOFF让下一个 Agent 接手
→
05MAINTAIN持续治理与更新

WHO IT IS FOR

适合已经开始认真使用 AI，
但上下文越来越失控的人。

  • 同时使用多个模型或 Agent，却总要重复解释背景
  • 知识、任务与规则散落在不同工具中，难以交接
  • 希望 AI 不只回答问题，而是参与长期工作
  • 需要为团队或业务流程建立可维护的 AI 接入层
